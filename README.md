# ESP32 Smart Vending Machine



\## Project Overview



An ESP32-based two-product smart vending machine featuring

keypad authentication, automatic product dispensing,

a 30-second security lock, and planned Python GUI-based

wallet and inventory management.



\## Hardware Components



\- ESP32 Development Board

\- 4x4 Matrix Keypad

\- 16x2 I2C LCD

\- Two 28BYJ-48 Stepper Motors

\- Two ULN2003 Motor Drivers

\- External 5V Motor Power Supply
